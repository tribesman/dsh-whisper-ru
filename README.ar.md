# التعرّف المحلي على الكلام باستخدام Whisper من أجل DeepSeek Harness

إضافة لـ DeepSeek Harness (DSH) تضيف **مُعرّف Whisper محليًا** إلى الإدخال الصوتي، بحيث يعمل الإملاء باللغة **الروسية** وتسع لغات أخرى دون إرسال الصوت إلى أي خدمة سحابية.

يأتي DSH بمُعرّف واحد — SenseVoiceSmall — لا يعرف نموذجه إلا الصينية والإنجليزية والكانتونية واليابانية والكورية. تسجّل هذه الإضافة مزوّدًا ثانيًا في السجل نفسه، وتعرضه واجهة الإدخال الصوتي القائمة مع قائمة اللغات أدناه.

## ما الذي تحصل عليه

- مسار **الإملاء عبر الميكروفون** الموجود أصلًا في DSH يعمل دون تغيير؛ الجديد هو المُعرّف وحده.
- **عشر تلميحات لغوية:** `auto`، الروسية، الإنجليزية، الألمانية، الإسبانية، الفرنسية، البرتغالية، اليابانية، الصينية، الكورية.
- **تعرّف دون اتصال بالكامل.** يسجّل المتصفح الصوت، وتفرّغه عملية فرعية على الجهاز الذي يعمل عليه DSH، ولا يُرفع الصوت إلى أي مكان.
- **نماذج موثّقة.** يُثبَّت كل ملف checkpoint بحجمه وبـ SHA-256 قبل استخدامه.
- **تنصيب صريح.** تُنزَّل النماذج مرة واحدة، وعند الطلب، مع إظهار التقدّم والإلغاء وإعادة المحاولة في إعدادات إضافة الصوت.

## المتطلبات

| البند | القيمة |
| --- | --- |
| DSH | 0.2.x مع تفعيل حزمة **الإدخال الصوتي** الاختيارية |
| النظام | macOS arm64/x64، وLinux x64/arm64 (glibc)، وWindows x64 |
| القرص | نحو 0.4 GB للنموذج الافتراضي (انظر جدول النماذج) |
| الذاكرة | نحو 0.8 GB أثناء تحميل نموذج |
| الحوسبة | CPU فقط؛ لا حاجة إلى GPU أو Python أو مُصرِّف |
| الشبكة | تنزيل النموذج مرة واحدة (Hugging Face أو HF-Mirror) |

## التثبيت

1. افتح **Plugins (الإضافات)** في DSH وانقر على **Add plugin (إضافة ملحق)**.
2. الصق هذا العنوان وأكّد:

   ```text
   github:tribesman/dsh-whisper-ru
   ```

3. افتح تفاصيل إضافة **الإدخال الصوتي** واضغط على **Download and prepare (تنزيل وتحضير)**. يستغرق النموذج الافتراضي `small` نحو 376 MB.
4. في صفحة التفاصيل نفسها اختر **Recognition service (خدمة التعرّف) → Whisper small (INT8)** و**Recognition language (لغة التعرّف) → Русский**.

تستخدم الواجهة الروسية الصفوف نفسها: **Плагины → Добавить плагин**، ثم في تفاصيل إضافة الصوت **Скачать и подготовить**، **Служба распознавания**، **Язык распознавания**.

أما التحديث لاحقًا فيستخدم نافذة **Add plugin (إضافة ملحق)** نفسها وبالعنوان نفسه؛ ويعيد DSH تثبيت الحزمة من المستودع.

## النماذج

ينزّل المزوّد ملف checkpoint واحدًا متعدد اللغات من Whisper بتكميم INT8. اختره بمفتاح الإعداد `model`.

| `model` | الحجم على القرص (تقريبًا) | الذاكرة (تقريبًا) | السرعة على CPU حاسوب محمول | جودة الروسية |
| --- | --- | --- | --- | --- |
| `tiny` | 103 MB | 0.23 GB | الأسرع، أسرع عدة مرات من الزمن الحقيقي | مقبولة، الأفضل للعبارات القصيرة |
| `base` | 161 MB | 0.35 GB | سريع | جيدة |
| `small` (الافتراضي) | 376 MB | 0.83 GB | نحو الزمن الحقيقي | جيدة جدًا |
| `medium` | 947 MB | 2.1 GB | أبطأ من الزمن الحقيقي | الأفضل، ويتطلب 8 GB+ من RAM الحرة |

النماذج الأربعة كلها ملفات checkpoint متعددة اللغات من Whisper منشورة لـ sherpa-onnx. التعرّف على CPU فقط، لذا يستغرق التسجيل الأطول وقتًا أطول بالتناسب.

## اللغات

`auto` (كشف تلقائي)، `ru`، `en`، `de`، `es`، `fr`، `pt`، `ja`، `zh`، `ko`.

- يتيح `auto` لـ Whisper كشف اللغة من التسجيل؛ ومع المقاطع القصيرة يكون التلميح الصريح أكثر موثوقية.
- تغيير التلميح يعيد إنشاء المُعرّف، وهو ما يكلّف ثانية أو ثانيتين في التسجيل التالي.
- قائمة اللغات ثابتة في هذا المزوّد. وإضافة لغة أخرى من لغات Whisper تعني تعديل `LANGUAGES` في `index.js`.

## الخصوصية

- ينتقل التسجيل من الصفحة إلى DSH Host عبر واجهة API المحلية القائمة، ثم إلى عملية فرعية تابعة لـ Host.
- لا يُرسل أي صوت أو نص أو بيانات وصفية إلى أي خدمة خارجية. الطلبات الصادرة الوحيدة هي تنزيلات النماذج من الأصل الذي تراه في بطاقة التنصيب.
- توجد النماذج تحت `$DSH_HOME/speech-to-text/whisper/<model>/` (افتراضيًا `~/.dsh/speech-to-text/whisper/<model>/`). حذف هذا الدليل يزيل النماذج؛ وحينها تُبلغ الإضافة بأن النموذج غير مُحضَّر.
- إيقاف الإضافة يحرّر العملية الفرعية للمُعرّف ويُبقي النماذج المنزّلة.

## الإعداد

تُدرج الحزمة صفًا واحدًا هو `speech-to-text-whisper`. تجاوزه في رقعة الملف الشخصي (`~/.dsh/profiles/<profile>/cordis.patch.yml`):

```yaml
- id: speech-to-text-whisper
  name: dsh-whisper-ru
  config:
    model: small
    dataRoot: /Users/me/.dsh/speech-to-text/whisper
    threads: 4
    modelOrigins:
      - https://huggingface.co
      - https://hf-mirror.com
```

| المفتاح | الافتراضي | المعنى |
| --- | --- | --- |
| `model` | `small` | `tiny` أو `base` أو `small` أو `medium` |
| `dataRoot` | `$DSH_HOME/speech-to-text/whisper` | دليل مطلق للنماذج المنزّلة |
| `threads` | `4` | خيوط CPU المستخدمة في عملية تعرّف واحدة |
| `providerId` | `whisper-local` | معرّف السجل الذي تختاره الإضافات الأخرى |
| `modelOrigins` | Hugging Face، HF-Mirror | الأصول التي تُقارن عند بدء التنزيل |
| `modelOrigin` | غير مضبوط | استخدام هذا الأصل بالضبط، دون بديل احتياطي |
| `inferenceTimeoutMs` | `300000` | المهلة النهائية لعملية تعرّف واحدة |

تغيير `model` يغيّر مجموعة الملفات، لذا يجب تحضير النموذج الجديد مرة أخرى؛ وتبقى الملفات القديمة على القرص حتى تحذفها.

## كيف يعمل

```
browser microphone → DSH voice input → speechToText registry
    → this provider (index.js) → worker.js subprocess
        → sherpa-onnx + Whisper INT8 → text back to the draft
```

- يسجّل `index.js` المزوّد، ويتولّى تحضير النماذج (التنزيل، والتحقّق بـ SHA-256، وملف `.verified.json` المرافق)، ويشغّل العامل عند أول تسجيل.
- يعمل `worker.js` في عملية Node منفصلة، بحيث لا يعيق أي كلام طويل DSH Host. ويحلّل بنفسه ملف WAV القياسي 16 kHz أحادي القناة PCM16، لأن الإضافة الأصلية (native addon) لا تستطيع تسليم V8 مخزنًا خارجيًا داخل Electron.
- يمكن إلغاء التعرّف على التسجيل الحالي من الواجهة؛ والإلغاء يُنهي العامل، ويبدأ التسجيل التالي عاملًا جديدًا.

## استكشاف الأخطاء وإصلاحها

| العَرَض | ما ينبغي فعله |
| --- | --- |
| "the recognition model is not prepared yet" (لم يُحضَّر نموذج التعرّف بعد) | افتح تفاصيل إضافة الصوت واضغط على **Download and prepare (تنزيل وتحضير)**. |
| فشل التنزيل بخطأ شبكة أو خطأ HTTP | أعد المحاولة؛ وإذا كان Hugging Face بطيئًا أو محجوبًا، فاختر **HF-Mirror** مصدرًا للتنزيل في البطاقة نفسها. ويجب ضبط وكيل (proxy) على الجهاز الذي يعمل عليه DSH. |
| التعرّف بطيء | بدّل `model` إلى `base` أو `tiny` وحضّره؛ وأبقِ `threads` عند عدد أنوية الأداء. |
| لا يوجد ميكروفون في الواجهة | يجب أن تُقدَّم الصفحة عبر HTTPS أو على loopback؛ واسمح بالوصول إلى الميكروفون في المتصفح وفي إعدادات النظام. |
| التعرّف الأول يتوقف بضع ثوانٍ | العامل يحمّل النموذج. وتعيد التسجيلات اللاحقة استخدامه حتى يصبح خاملًا. |
| النص بلا علامات ترقيم | يضيف Whisper علامات الترقيم بنفسه؛ وقد تفقدها المقاطع القصيرة أو المشوّشة. |

## القيود

- تسجيلات كاملة فقط — لا نص متدفق، ولا كلمة تنبيه، ولا تخليق للكلام.
- على CPU فقط، ويستقبل العامل تسجيلًا واحدًا في كل مرة.
- قد يختلق Whisper كلمات في الصمت أو الموسيقى؛ فاحرص على أن تكون التسجيلات نظيفة.
- لم يُتحقّق من Windows على ARM ولا من Linux musl، لأن وقت تشغيل sherpa-onnx المُجهّز مسبقًا لا يستهدفهما.
- يُتعرَّف على الروسية بحالة الأحرف وعلامات الترقيم الخاصة بـ Whisper، وقد تختلف عن النص الذي تكتبه بنفسك.

## التطوير

```bash
git clone https://github.com/tribesman/dsh-whisper-ru
cd dsh-whisper-ru
pnpm install
```

الحزمة ESM خالصة بلا خطوة بناء: `index.js` هو إضافة Host، و`worker.js` عمليتها الفرعية، و`cordis.patch.yml` يُدرج الصف. ويمكن تثبيت نسخة محلية من المستودع عبر **Add plugin (إضافة ملحق)** ومسار دليلها المطلق.

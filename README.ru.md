# Локальное распознавание речи Whisper для DeepSeek Harness

Плагин DeepSeek Harness (DSH), который добавляет в голосовой ввод **локальный распознаватель Whisper**, так что диктовка работает на **русском** и ещё девяти языках без отправки аудио в облачный сервис.

В DSH есть только один распознаватель — SenseVoiceSmall, — и его модель знает лишь китайский, английский, кантонский, японский и корейский. Этот плагин регистрирует второго провайдера в том же реестре, и существующий интерфейс голосового ввода предлагает его со списком языков ниже.

## Что вы получаете

- **Диктовка с микрофона**, которая уже есть в DSH, работает без изменений; новое здесь — только распознаватель.
- **Десять языковых подсказок:** `auto`, русский, английский, немецкий, испанский, французский, португальский, японский, китайский, корейский.
- **Полностью офлайновое распознавание.** Аудио записывается браузером, расшифровывается подпроцессом на машине с DSH и никуда не загружается.
- **Проверенные модели.** Каждый файл чекпоинта закреплён по размеру и SHA-256 до того, как он будет использован.
- **Явная настройка.** Модели скачиваются один раз, по запросу, с прогрессом, отменой и повтором в настройках голосового плагина.

## Требования

| Пункт | Значение |
| --- | --- |
| DSH | 0.2.x с включённым опциональным бандлом **voice input (голосовой ввод)** |
| Система | macOS arm64/x64, Linux x64/arm64 (glibc), Windows x64 |
| Диск | около 0.4 ГБ для модели по умолчанию (см. таблицу моделей) |
| Память | около 0.8 ГБ при загруженной модели |
| Вычисления | только CPU; GPU, Python и компилятор не нужны |
| Сеть | однократное скачивание модели (Hugging Face или HF-Mirror) |

## Установка

1. Откройте **Plugins (Плагины)** в DSH и нажмите **Add plugin (Добавить плагин)**.
2. Вставьте этот адрес и подтвердите:

   ```text
   github:tribesman/dsh-whisper-ru
   ```

3. Откройте подробности плагина **voice input (голосовой ввод)** и нажмите **Download and prepare (Скачать и подготовить)**. Модель `small` по умолчанию занимает около 376 МБ.
4. На той же странице подробностей выберите **Recognition service (Служба распознавания) → Whisper small (INT8)** и **Recognition language (Язык распознавания) → Русский**.

В русском интерфейсе используются те же строки: **Плагины → Добавить плагин**, затем в подробностях голосового плагина — **Скачать и подготовить**, **Служба распознавания**, **Язык распознавания**.

При обновлении позже используется тот же диалог **Add plugin (Добавить плагин)** с тем же адресом; DSH переустанавливает пакет из репозитория.

## Модели

Провайдер скачивает один многоязычный чекпоинт Whisper в квантовании INT8. Выбирается он ключом конфигурации `model`.

| `model` | Диск (примерно) | Память (примерно) | Скорость на CPU ноутбука | Качество русского |
| --- | --- | --- | --- | --- |
| `tiny` | 103 МБ | 0.23 ГБ | самый быстрый, в несколько раз быстрее реального времени | удовлетворительное, лучше всего для коротких фраз |
| `base` | 161 МБ | 0.35 ГБ | быстрый | хорошее |
| `small` (по умолчанию) | 376 МБ | 0.83 ГБ | около реального времени | очень хорошее |
| `medium` | 947 МБ | 2.1 ГБ | медленнее реального времени | лучшее, требует 8 ГБ+ свободной RAM |

Все четыре — многоязычные чекпоинты Whisper, опубликованные для sherpa-onnx. Распознавание идёт только на CPU, поэтому более длинная запись обрабатывается пропорционально дольше.

## Языки

`auto` (определение), `ru`, `en`, `de`, `es`, `fr`, `pt`, `ja`, `zh`, `ko`.

- `auto` позволяет Whisper определить язык по записи; на коротких фрагментах явная подсказка надёжнее.
- Переключение подсказки пересоздаёт распознаватель, что стоит секунду-другую при следующей записи.
- Список языков фиксирован этим провайдером. Чтобы добавить другой язык Whisper, отредактируйте `LANGUAGES` в `index.js`.

## Конфиденциальность

- Запись идёт со страницы в DSH Host по существующему локальному API, а затем в дочерний процесс Host.
- Ни аудио, ни текст, ни метаданные не отправляются во внешние сервисы. Единственные исходящие запросы — скачивание моделей с источника, который вы видите в карточке настройки.
- Модели лежат в `$DSH_HOME/speech-to-text/whisper/<model>/` (по умолчанию `~/.dsh/speech-to-text/whisper/<model>/`). Удаление этого каталога удаляет модели; после этого плагин сообщает, что модель не подготовлена.
- Отключение плагина освобождает подпроцесс распознавателя и сохраняет скачанные модели.

## Конфигурация

Бандл вставляет одну строку, `speech-to-text-whisper`. Переопределите её в патче профиля (`~/.dsh/profiles/<profile>/cordis.patch.yml`):

```yaml
- id: speech-to-text-whisper
  name: dsh-whisper-ru
  config:
    model: small
    dataRoot: /Users/me/.dsh/speech-to-text/whisper
    threads: 4
    modelOrigins:
      - https://huggingface.co
      - https://hf-mirror.com
```

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `model` | `small` | `tiny`, `base`, `small` или `medium` |
| `dataRoot` | `$DSH_HOME/speech-to-text/whisper` | абсолютный каталог для скачанных моделей |
| `threads` | `4` | потоки CPU, используемые одним распознаванием |
| `providerId` | `whisper-local` | id в реестре, который выбирают другие плагины |
| `modelOrigins` | Hugging Face, HF-Mirror | источники, сравниваемые при начале скачивания |
| `modelOrigin` | не задано | использовать ровно этот источник, без резервного |
| `inferenceTimeoutMs` | `300000` | предельное время одного распознавания |

Смена `model` меняет набор файлов, поэтому новую модель нужно подготовить заново; старые файлы остаются на диске, пока вы их не удалите.

## Как это работает

```
browser microphone → DSH voice input → speechToText registry
    → this provider (index.js) → worker.js subprocess
        → sherpa-onnx + Whisper INT8 → text back to the draft
```

- `index.js` регистрирует провайдера, отвечает за подготовку модели (скачивание, проверку SHA-256, сайдкар `.verified.json`) и запускает воркер при первой записи.
- `worker.js` работает в отдельном процессе Node, поэтому длинная фраза никогда не блокирует DSH Host. Он сам разбирает канонический WAV 16 kHz mono PCM16, потому что нативный аддон не может передать V8 внешний буфер внутри Electron.
- Распознавание текущей записи можно отменить из интерфейса; отмена убивает воркер, а следующая запись запускает новый.

## Устранение неполадок

| Симптом | Что делать |
| --- | --- |
| "the recognition model is not prepared yet" (модель распознавания ещё не подготовлена) | Откройте подробности голосового плагина и нажмите **Download and prepare (Скачать и подготовить)**. |
| Скачивание падает с сетевой ошибкой или ошибкой HTTP | Повторите попытку; если Hugging Face медленный или заблокирован, выберите **HF-Mirror** как источник загрузки в той же карточке. Прокси нужно настроить для машины, на которой работает DSH. |
| Распознавание идёт медленно | Переключите `model` на `base` или `tiny` и подготовьте её; держите `threads` равным числу производительных ядер. |
| В интерфейсе нет микрофона | Страница должна открываться по HTTPS или через loopback; разрешите доступ к микрофону в браузере и в системных настройках. |
| Первое распознавание зависает на несколько секунд | Воркер загружает модель. Последующие записи используют её, пока он не простаивает. |
| В тексте нет знаков препинания | Whisper расставляет их сам; короткие или шумные фрагменты могут их потерять. |

## Ограничения

- Только целиком записанные файлы — без потоковых субтитров, слова активации и синтеза речи.
- Только CPU, и воркер обрабатывает одну запись за раз.
- Whisper может выдумывать слова на тишине или музыке; записывайте чисто.
- Windows на ARM и Linux musl не проверены, потому что готовый runtime sherpa-onnx не поддерживает их.
- Русский распознаётся с собственными регистром и пунктуацией Whisper, которые могут отличаться от того, что вы набрали бы.

## Разработка

```bash
git clone https://github.com/tribesman/dsh-whisper-ru
cd dsh-whisper-ru
pnpm install
```

Пакет — чистый ESM без шага сборки: `index.js` — плагин Host, `worker.js` — его подпроцесс, а `cordis.patch.yml` вставляет строку. Локальную копию можно установить через **Add plugin (Добавить плагин)**, указав абсолютный путь к каталогу.
